# CTF Web

Use this skill only for web or mixed challenges with a web surface.

## Focus

- Map routes, APIs, parameters, auth flow, and trust boundaries.
- Prefer HTTP replay over repeated browser actions.
- Use Playwright for login, JavaScript-only behavior, and evidence capture.
- Convert repeated manual requests into a Python solver.
- Record request and response metadata without leaking credentials.
