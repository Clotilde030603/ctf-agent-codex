## Review Checks

- Every command appears in the event ledger or final reproduction record.
- File names, offsets, endpoints, and payloads match artifacts.
- The solver description matches `solve.py`.
- The flag matches the Accepted submission.
- Evidence images exist and are listed in `manifest.json`.
- No secrets appear in prose, code blocks, logs, or screenshots.
